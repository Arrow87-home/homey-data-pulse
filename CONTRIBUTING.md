# Contributing to Data Pulse

Bug reports and pull requests are welcome. Data Pulse is developed around actual use and the time available to maintain it.

## Reporting a bug

Search [existing issues](https://github.com/Arrow87-home/homey-data-pulse/issues) first. If the problem is not already reported, include:

- Clear steps to reproduce it.
- What you expected and what actually happened.
- Your Data Pulse version, Homey model and Homey software version.
- Relevant logs or screenshots with credentials and personal information removed.

For usage questions and general discussion, use the [Homey Community topic](https://community.homey.app/t/159768). Report sensitive security or privacy problems as described in [SECURITY.md](SECURITY.md), not in a public bug report.

## Proposing a change

Keep pull requests small and focused, and explain the problem they solve. Discuss larger architectural changes in a GitHub issue before implementing them.

Add or update tests when behaviour changes. Tests, lint and build must pass; `npm run check` also runs formatting and Homey debug validation. See the [development instructions](README.md#development) to get started.

Suggestions do not guarantee a roadmap commitment, review date or merge. A focused explanation and a reproducible example make contributions easier to assess.
