# Security and privacy reports

Please do not open a public issue containing sensitive exploit or security details.

Use GitHub **Private Vulnerability Reporting** from this repository's Security tab when it is available. If private reporting is not available, post only a non-sensitive request for a private contact method, without disclosing the vulnerability.

Never share credentials, access tokens, personal information or exploit details publicly, including in issues, pull requests, screenshots or logs. Wait until a private reporting channel has been established before sharing sensitive information.
